# Luna Browser updates

Здесь публикуются только файлы обновлений Luna Browser для iPhone и update.json.
Исходный код находится в отдельном приватном репозитории.

Luna автоматически проверяет update.json при открытии приложения. IPA проверяется по размеру и SHA-256.
Файлы IPA не подписаны: для установки используйте iLoader и свой Apple ID.
Не удаляйте установленное приложение перед обновлением, если хотите сохранить его данные.

Публичный файл версий: https://raw.githubusercontent.com/NixxxX-3216/-luna-updates/main/update.json
